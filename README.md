# Baby Raavi Gender Reveal — GitHub Pages

A mobile-friendly gender reveal invitation website.

## Quick setup

1. Create a GitHub repository, e.g. `gender-reveal`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. The reveal date/time is already configured for November 7, 2026 at 3:00 PM Eastern.
4. The invitation has already been personalized with the provided family, date, location, and RSVP information.
5. Commit the changes.
6. In GitHub, go to **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select your main branch and `/ (root)`, then save.
9. GitHub will provide your public `github.io` URL.

## Google Form

Create your RSVP form in Google Forms and paste its sharing URL into:

`YOUR_GOOGLE_FORM_URL_HERE`

## Optional: custom domain

GitHub Pages also supports a custom domain. Add it later under:

**Repository → Settings → Pages → Custom domain**

## Notes

The Team Boy / Team Girl guess is a fun local interaction. It is stored only in each visitor's browser and is not a guest-counting system. Use the Google Form for actual RSVPs.
